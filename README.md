# 青柠学园 · 智慧校园管理系统

一个面向学生日常的校园信息入口，把课程表、成绩、考勤、社团、通知集中在同一个页面里。视觉上刻意避开常见的「AI 风」——不用紫蓝渐变、玻璃拟态、发光边框和大圆角白卡片，而是做成日系校园手账的样子：奶油纸底、墨线描边、硬投影、彩色索引贴导航。

## 运行方式

纯静态页面，零依赖、无需构建、不用装任何环境：

```
双击 index.html，浏览器直接打开
```

如果想用本地服务器：

```bash
python -m http.server 8777
# 打开 http://localhost:8777
```

## 功能模块

| 模块 | 内容 |
|---|---|
| 总览 | 今日课程、学业数据看板、成绩趋势折线图、待办与最近通知 |
| 课程表 | 一周课表网格，点击任意课程查看教师、教室、教材与作业详情 |
| 成绩单 | 各科成绩与班级均分对比、等级评定、学期趋势 |
| 考勤 | 十月日历出勤标记（迟到 / 请假 / 缺勤）、出勤率统计、明细记录 |
| 社团 | 社团卡片与报名，每学期最多加入 2 个（超出会提示） |
| 通知 | 通知列表、未读角标、右侧抽屉集中查看、一键已读 |
| 我的 | 个人档案、徽章墙、心情贴纸、设置项开关 |

## 交互细节

- 单页应用，七个页面无刷新切换
- 课程、通知详情用弹窗展示；通知列表用右侧抽屉
- 顶栏搜索支持 `/` 快捷键唤起，输入关键词直接跳转对应页面
- 支持 Esc 逐层关闭弹窗与抽屉
- 移动端适配，无横向溢出

## 技术实现

- 原生 HTML / CSS / JavaScript，无框架、无构建工具、无第三方库
- 设计令牌用 CSS 自定义属性（`--tone` / `--tone-lt` / `--tone-dk`），通过 `data-tone` 属性切换配色
- 布局与视图分离：每个页面是一个返回 HTML 字符串的纯函数，数据集中在文件顶部
- 事件用单个全局代理监听，按 `data-act` 分发
- 无障碍：`focus-visible`、`prefers-reduced-motion`、`aria-current` / `aria-pressed` / `role="switch"` 等

## 文件结构

```
index.html    页面骨架、侧栏、顶栏、弹窗与抽屉容器
styles.css    完整设计系统（令牌 / 组件 / 七个页面样式 / 响应式）
app.js        数据层、视图函数、路由与交互逻辑
```

## 数据说明

页面内所有数据（课程、成绩、考勤、社团、通知）均为演示用示例数据，集中写在 `app.js` 顶部，替换成真实接口时只需改动这一处。
